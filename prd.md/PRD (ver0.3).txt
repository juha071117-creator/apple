# PRD (ver0.3)

**작성 근거** · 이 페이지의 **PRD (ver0.2)**, 9주차, 이번 대화에서 확정한 모바일 화면과 `study-mate.html` 와이어프레임

**이번 개정** · 갤럭시 S26 기준 모바일 화면에서 상단 헤더와 하단 4개 탭을 고정한다. 홈에서 최근 계획을 다시 열고, 학습계획 탭에서는 새로 작성하며, 마이페이지에서 내 계획과 학교 정보를 관리한다. 학교·과목별 공유 검색과 커리큘럼 자료 첨부의 동작을 구체화한다.

## 1. 프로젝트 소개

- **서비스명** · 스터디메이트(StudyMate)
- **서비스 형태** · 대학생이 학습 범위와 공부 가능 시간을 입력하면 GPT가 최대 1주의 맞춤 학습계획을 구성하는 웹 서비스
- **사용 목적** · 시험 대비, 수업 복습, 프로젝트, 자기계발, 취미, 자격증 등 다양한 학습 목적을 지원한다. 시험일 입력은 시험 대비에서만 요구한다.
- **핵심 흐름** · 계획 작성 → 결과 검토·저장 → 홈 또는 마이페이지에서 재열람 → 원하는 계획을 공유하고 학교·과목으로 찾아보기

## 2. 사용자·문제·가치

수업과 개인 일정을 함께 관리하는 대학생은 제한된 공부 시간에 어떤 내용을 어떤 순서로 학습할지 결정하기 어렵다. 스터디메이트는 공부 가능 시간에 맞춰 학습 순서를 정리하고, 저장한 계획을 다시 열거나 같은 학교 또는 다른 학교의 유사 과목 계획을 참고할 수 있게 한다.

4주차에는 대학생 시간 관리와 학업 지연 관련 선행연구를 조사했다. 계획 작성 부담이 줄어드는지, 공유 계획이 학습에 도움이 되는지는 실제 사용자 평가에서 확인한다.

## 3. 범위와 현재 상태

| 우선순위 | 제품 요구사항 |
| --- | --- |
| Must | 공통 고정 헤더·하단 탭, 홈 안내·최근 계획, 계정별 가입·로그인·로그아웃과 저장, 새 입력 초기화, 목적별 학습계획, 파일·URL 첨부, GPT 1주 계획 생성·결과·시간 검증, 내 계획·학교 등록, 학교·과목 공유 검색·게시 |
| Should | 현재 결과에서 입력 수정·재생성, 필수 입력·첨부·GPT 오류 안내 |
| Could | 계획 텍스트 복사 |
| 이후 범위 | 개념 설명·문제 힌트, 여러 과목의 장기 일정 통합 |

**HTML 와이어프레임 범위** · 네 탭, 로그인 상태 전환, 수동 계획 작성과 커리큘럼 단계 추가, 로컬 저장·재열람, 학교 등록, 예시 및 같은 브라우저에서 공유한 계획 검색을 시연한다. 가입·실제 계정 인증, 계정별 접근 제어, GPT 계획 생성·시간 검증, 사용자 간 공유와 공개본 분리는 제품 구현 항목이다. 현재 시연의 공유 상세에는 첨부 자료가 표시될 수 있으므로, 실제 공유본을 만들 때는 아래 공개 항목 기준을 적용한다.

## 4. 화면 구조와 이동

| 화면 ID | 탭·화면 | 역할 |
| --- | --- | --- |
| S-00 | 홈 | 스터디메이트 안내, 최근 저장한 계획 카드 1개, 학교·과목 검색 진입을 제공한다. 최근 카드에서 계획 상세를 연다. |
| S-03 | 목록 | 공유 계획을 학교만 또는 학교와 과목으로 검색하고 공개 상세를 연다. |
| S-01 | 학습계획 | 탭에 새로 진입할 때마다 빈 양식을 연다. 학습 목적·조건과 커리큘럼을 입력한다. |
| S-02 | 학습계획 결과 | 날짜별 학습 내용·시간을 검토하고 저장한다. 현재 결과에서 ‘입력 수정’을 누르면 작성 중인 값으로 돌아간다. |
| S-06 | 마이페이지 | ‘내 계획’ 전체 목록과 상세, 학교 등록·변경, 등록한 학교의 공유 목록 진입, 로그아웃을 제공한다. |
| S-04·S-05 | 로그인·회원가입 | 로그인 화면에서 회원가입에 진입한다. 제품에서는 게스트가 홈·목록을 둘러보고, 학습계획·마이페이지 진입 시 로그인으로 안내한다. |
- **공통 레이아웃** · 갤럭시 S26 세로 화면을 기준으로 360 × 780 CSS 픽셀의 와이어프레임을 사용한다. 상단 ‘스터디메이트’ 헤더와 하단 **홈 → 목록 → 학습계획 → 마이페이지**를 고정하고 가운데 본문만 스크롤한다. 헤더의 서비스명을 누르면 홈으로 이동한다. 화면에 휴대폰 외형, 모의 상태바, 카메라 홀, 제스처 바는 넣지 않는다.
- **색상** · 검정과 흰색에 코픽마카 C 계열을 참고한 푸른빛 쿨그레이를 사용한다. 카드와 입력 테두리, 선택된 하단 탭, 일러스트에 같은 팔레트를 적용한다. 코픽 공식 Cool Gray 색상표
- **로그인 상태** · 로그인 전후에 헤더·탭의 위치와 순서, 홈 안내 배치를 유지한다. 최근 계획 영역은 제품에서 게스트 안내, 로그인 후 저장 기록이 없는 빈 상태, 최근 카드로 구분한다.
- **중복 정리** · 홈은 최근 계획 1개를 보여주고, 전체 목록은 마이페이지 ‘내 계획’에서 관리한다. 날짜별 계획은 계획 상세에서 확인한다.

## 5. 기능 요구사항

| 기능 | 완료 조건 |
| --- | --- |
| 새 학습계획 | 다른 탭을 거쳐 학습계획에 다시 들어오면 제목·과목·목적·목표·커리큘럼 등 이전 미저장 입력이 비워진다. 현재 결과의 ‘입력 수정’에서는 값을 유지한다. 저장한 계획은 마이페이지에서 다시 연다. |
| 학습 목적과 기간 | 공통 입력은 과목 또는 주제, 시작일, 학습 범위, 공부 가능 시간이다. 과목명은 직접 입력한다. 시험 대비는 시험일 필수, 시험 방식 선택으로 두고 시험일 전까지만 배치한다. 그 외 목적은 시험 입력을 숨기고 시작일부터 최대 7일간 배치한다. |
| 커리큘럼 자료 | 단계별 파일과 URL을 각각 또는 함께 등록한다. 작성 화면에서 첨부 상태를 확인하고 제거할 수 있다. 내 계획 상세에서 등록한 파일과 URL을 다시 연다. |
| 생성·검증 | GPT가 입력한 범위와 공부 가능 시간을 반영한다. 결과에는 날짜별 학습 내용과 시간을 표시한다. 공부 가능 시간 밖의 배치와 시험일 이후의 배치를 검증한다. |
| 저장·재열람 | 저장할 때 새 계획을 추가한다. 홈에는 본인의 가장 최근 계획 1개, 마이페이지에는 본인의 저장 계획 전체를 표시한다. |
| 학교 등록·검색 | 마이페이지에서 학교를 검색해 등록·변경한다. ‘동양미래대’와 ‘동양미래대학교’를 같은 학교로 취급한다. 등록한 학교의 공유 목록을 바로 열 수 있고, 과목을 함께 입력하면 두 조건에 맞는 계획만 표시한다. |
| 게시·공개 범위 | 제품에서는 저장한 계획의 공개 내용을 미리 보여주고 동의를 받아 게시한다. 공유본에는 학교·과목·학습 주제와 순서를 표시한다. 개인 일정, 정확한 날짜·시간, 첨부 파일·URL, 시험 세부정보는 공개본에서 제외한다. |

**검색 예시** · 목록에서 ‘동양미래대’와 ‘웹프로그래밍’을 입력하면 동양미래대학교 웹프로그래밍 공유 계획을 표시한다. 동일 학교라도 다른 과목은 해당 결과에서 제외한다.

## 6. 테스트 방법과 성공 기준

| 검증 항목 | 성공 기준 |
| --- | --- |
| 모바일 스크롤·탭 | S26 기준 화면에서 긴 본문을 스크롤해도 헤더와 네 탭이 계속 보인다. 탭을 누르면 해당 화면으로 이동하고 새 화면의 본문이 맨 위에서 시작한다. |
| 로그인 상태 | 로그인 전후 헤더·탭의 배치가 같다. 제품에서 다른 계정의 계획은 홈·마이페이지에 표시되지 않는다. |
| 신규 입력과 목적 | 미저장 양식 작성 중 다른 탭에 갔다 돌아오면 빈 양식이다. 현재 결과에서 입력 수정 시 값이 남는다. 시험 대비는 시험일이 필요하며, 취미·복습 등은 시험일 없이 작성할 수 있다. |
| 자료 등록 | 한 단계에 파일과 URL을 함께 등록하고 저장한 뒤 내 계획 상세에서 열 수 있다. 실제 공유 상세에는 자료가 표시되지 않는다. |
| 최근 계획과 내 계획 | 계획 두 개를 저장하면 홈에는 마지막에 저장한 1개, 마이페이지에는 2개가 표시되고 각 상세를 열 수 있다. |
| 학교·과목 검색 | ‘동양미래대’로 학교를 등록한 뒤 공유 목록을 열 수 있다. ‘웹프로그래밍’을 추가하면 해당 과목만 보인다. |
| GPT 결과 검증 | 최대 7일 안에서 조건에 맞게 배치되며, 공부 가능 시간이나 시험일 제약을 벗어난 항목을 확인할 수 있다. |

**검증 상태** · HTML의 학교명 정규화, 검색 필터, 최근 카드 및 내 계획 표시 로직을 코드로 확인했다. S26 실기기 스크롤, 파일 첨부의 실제 브라우저 동작, 계정 분리, GPT 결과, 사용자 간 공유는 검증할 항목이다. 대학생 사용자에게 작성·저장·재열람·검색을 수행하게 한 뒤 이해도와 실용성을 기록한다.

## 7. 후속 작업과 결정 사항

- S26 실기기에서 고정 영역, 탭 전환, 폼 입력과 파일 첨부 흐름을 검증한다.
- 기존 규칙 기반 시연을 기준으로 GPT 연동, 기간·시간 검증, 입력 및 연결 오류 처리를 구현한다.
- 계정별 저장과 학교 정보를 연동하고, 공개 동의와 비공개 항목 제거를 적용한 공유본을 검증한다.
- **팀 결정 필요** · 학교 목록 출처·등록 확인 방식, 파일 형식·용량 및 URL 처리 범위, GPT 연동·비용, 테스트 인원·성공 기준, 담당자와 일정.
